Politique de confidentialité

Dernière mise à jour : 15 novembre 2026

Doc ? Médecin malgré lui est un jeu pour Android. Cette page explique quelles données le jeu utilise.

Ce que le jeu collecte : rien

  • Le jeu ne collecte aucune donnée personnelle : pas de nom, pas d’adresse e-mail, pas de position, pas de contacts, pas de photos, pas d’identifiant publicitaire.
  • Le jeu n’envoie aucune donnée sur Internet : il fonctionne entièrement hors ligne.
  • Il n’y a ni publicité, ni outil de statistiques, ni achat intégré, ni compte à créer.
  • Le jeu s’achète sur Google Play : le paiement est entièrement géré par Google, et le développeur ne reçoit aucune donnée de paiement (voir les règles de confidentialité de Google).

Ce que le jeu garde sur ton téléphone

  • Ta partie (chapitre, argent, maladies rencontrées…) et tes réglages (musique, bruitages, vibrations) sont enregistrés uniquement sur ton téléphone, pour que tu reprennes ta partie.
  • Le jeu ne les envoie nulle part. Elles sont effacées si tu désinstalles le jeu ou si tu vides les données de l’application dans les réglages d’Android.
  • Sauvegarde Android : si tu as activé la sauvegarde de ton téléphone sur ton compte Google, Android peut y copier ta partie, comme pour tes autres applications, afin de la retrouver sur un nouveau téléphone. Cette copie est gérée par Google et se règle dans les paramètres d’Android ; le développeur n’y a pas accès.

Autorisations

  • Vibreur : pour les petits retours quand tu touches l’écran (désactivable dans le jeu).
  • Internet : autorisation technique demandée par le moteur de l’application ; le jeu ne s’en sert pas pour envoyer ou recevoir des données.

Enfants

Le jeu ne collecte aucune donnée, y compris pour les enfants.

Ce site

Ce site n’utilise ni cookie, ni outil de statistiques, ni police ou script venant d’un autre site. Il est hébergé par GitHub Pages, qui peut enregistrer des informations techniques de connexion (comme l’adresse IP) pour la sécurité du service.

Important

Doc ? est un jeu simplifié : il ne remplace pas l’avis d’un médecin ou d’un pharmacien. En cas d’urgence, appelle le 15 (ou le 112).
